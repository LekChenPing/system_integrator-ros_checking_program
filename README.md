# system_integrator-ros_checking_program

This program was completed as part of my System Integrator job.

## Introduction
It provides a simple workflow for checking ROS setup, motor control, LiDAR connection, mapping, and navigation functions on Yahboom robots. The program also records test results and supports operator input when a check requires physical observation or further review.

## Problem Statement
Checking multiple robots manually is repetitive and can make the validation process inconsistent. This program was created to make the checking process more structured, repeatable, and easier to document.

## AI and Human Roles
The human defined the test requirements, workflow, success criteria, and final judgement based on actual robot behaviour. AI was used to help organise the program structure, generate and refine parts of the code, document the logic, and assist with troubleshooting during development.
